# 量子计算产业生态

## 一、量子计算概述

```
量子计算 vs 经典计算
│
├── 经典计算 (Classical)
│   ├── 比特 (Bit): 0 或 1
│   ├── 冯诺依曼架构
│   ├── 线性计算
│   └── 摩尔定律逼近物理极限
│
└── 量子计算 (Quantum)
    ├── 量子比特 (Qubit): 0, 1, 或叠加态
    ├── 量子并行性 (Quantum Parallelism)
    ├── 量子纠缠 (Entanglement)
    └── 指数级加速潜力
```
